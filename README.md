# Statistik Indonesia

Situs statistik nasional Indonesia — make.fun bounty
`best-national-statistics-site-20261126-0539`.

Beranda dengan 8 KPI (penduduk, PDB, pertumbuhan, inflasi, pengangguran,
kemiskinan, IPM, harapan hidup) dan pemilih tahun 2015–2024; halaman
Demografi (piramida penduduk + tabel umur), Ekonomi (PDB, inflasi, PDB per
kapita, perdagangan), Ketenagakerjaan, Kemiskinan & Kesejahteraan, Kesehatan
& Pendidikan, Provinsi (tabel 38 provinsi: cari, saring per pulau, urutkan
tiap kolom, bandingkan 2 provinsi, unduh CSV), Kalkulator (daya beli,
pertumbuhan majemuk, pangsa provinsi), dan Metodologi & Sumber.

Semua angka nyata dari BPS, Bank Indonesia, dan Kementerian Kesehatan
(2015–2024), berlabel tahun dan sumber di tiap halaman. Grafik digambar
dengan canvas di browser — tanpa library, tanpa network request. Mode
gelap/terang, layout desktop dan HP.

Jalankan lokal: `node serve.ts`, lalu buka http://localhost:8080.
